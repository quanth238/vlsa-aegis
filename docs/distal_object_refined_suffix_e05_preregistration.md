requires exact state-hash agreement. Only actions 230--236 are searched.

error against a parallel successful immutable AEGIS replay. The best four safe

26 nonzero ternary directions on the first action only. A fresh exact rollout
must verify the selected chunk before its first action is executed.

search family, not all continuous or live-policy recovery. No QP or learned
