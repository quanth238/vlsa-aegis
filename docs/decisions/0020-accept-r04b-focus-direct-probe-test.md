# 0020 — Accept R04B and focus the direct learned-probe test

Status: accepted on 2026-07-14 after source Slurm task `27558_0` and independent
CPU Slurm validator `27559` completed with zero errors.

## Context

The exact-resume seam was the last sampler apparatus uncertainty. It is now
allocation-backed: all zero-edit continuations at registered steps 1--5 match
their source features and final actions byte-for-byte, the current eager path
matches the independently validated R04A golden data, and the ordinary
compiled path is unchanged before and after the opt-in calls.

This result does not answer whether a learned probe works. Existing evidence
already localizes the scientific problem more sharply. R01 found direct
safe-progress witnesses for 17/20 frozen collision cases. R03 found that a
privileged distributed direction succeeds on 9/17 feasible cases while
equal-norm random and the registered one-midpoint analytic direction succeed
on 0/17. Four privileged misses are clearance-only and four are progress-only.
The remaining root risk is therefore learned-direction quality, local feature
support, intervention timing/nonlinear continuation, and the
clearance--progress conflict—not absence of a safe action.

The released task-0 Level-II state file is exhausted and no generator exists
in the repository. Plain BDDL reset creates all six obstacles and is not the
same population.

## Decision

1. Accept R04B as passed apparatus-only. Keep feature R04 active and do not
   claim prediction or steering efficacy.
2. Stop adding sampler/parity variants. Seek the benchmark authors' Level-II
   generator in parallel, but do not block the mechanism study on it.
3. Build an additive, explicitly new source population named
   `task0_single_obstacle_generated_v1`. Never call it official Level II.
   Preserve finalized XML, full state/history, hashes, rejection records, and
   fresh-load replay evidence. Never reject based on policy collision,
   clearance, probe output, planner success, or progress.
4. Re-run the measurement/progress, direct-feasibility, and privileged-flow
   authorization sequence on preregistered generated groups before collecting
   probe-training labels. Failure to transfer R03 blocks training.
5. The decisive confirmatory outcome is paired branch-inclusive Safe-Progress
   Success on untouched groups, not clearance alone. Pair state, observation,
   policy noise, saved latent, and executed horizon across frozen pi0.5, one
   locked ECG variant, realized-norm-matched random, a strong time-structured
   margin-stopped analytic controller, AEGIS, same-budget privileged direction,
   and direct verified planner arms. Include the closest reproducible
   constrained-flow optimizer as a system comparator; otherwise disclose that
   it was unavailable and make no comparison claim against it.
6. Report paired effect sizes and confidence intervals for both feasible and
   all-collision populations. Measure warmed batch-one end-to-end p50/p95
   latency on identical hardware, including geometry, gradients, and every
   safety/optimization solve. Offline search and training cost remain separate.
7. Architecture, input decomposition, time, and dose are selected once on
   disjoint development groups. The locked test is never used to choose a
   variant. Beating only frozen and random is insufficient for a strong
   research claim; learned necessity requires beating the strong analytic arm,
   and an efficiency claim against AEGIS/optimization requires a frozen safety
   superiority or noninferiority criterion plus a meaningful latency margin.

## Consequences

The next implementation is the independent generated-source seam and a retired
power/prevalence pilot. Production group counts are frozen only after that
pilot estimates valid-state, collision, boundary, unsafe, trigger-positive,
and direct-witness prevalence. Pilot and repeated R00--R03 groups cannot enter
training or locked evaluation.

The method remains falsifiable. A predictive probe with a noncausal gradient
is a monitor, not a steering method. A supported gradient that improves
clearance but loses progress fails the joint outcome. If strong analytic
guidance matches ECG, the learned probe is unnecessary for this setting.
