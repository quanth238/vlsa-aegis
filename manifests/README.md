# Case manifests

Case manifests are immutable JSONL files generated by `crfs-harness build-manifest`.
Every row fixes the SafeLIBERO episode, policy noise, equal-norm random-control
seed, and state-group identity. All nominal, direct-repair, random, residual,
and bridge-edit arms consume the same row.

Generated validation and test manifests are run artifacts and are not edited by
hand. A changed task, seed schedule, safety margin, checkpoint, or intervention
selection creates a new run ID and manifest rather than mutating old evidence.

`oracle_smoke.jsonl` is the checked-in one-case apparatus smoke. Its immutable
identity is part of the first allocation-backed audit; replace it only by
creating a new named manifest and recording the decision.
